# Patterns found in data via manual inspection

Approximately 1000 files were manually inspected from each set (fake and real) in train set to identify patterns in the data

**REAL DATA**:

- Diversity of face expressions and emotions
- More random objects (helmets, hats, microphones, etc)
- Diverse range of non-blurry backgrounds
- Features people with skin conditions/disorders more frequent
- More traditional clothing
- A lot of different age groups
- A lot of racial/ethnic diversity
- eyes are positioned randomly

**FAKE DATA**:

- Blurry backgrounds
- Roughly same face expressions
- Mostly light skin people
- Background (if not blurry) are unrealistic/distorted
- eyes are positioned in the same exact spots (same intraocular distance)
- pretty much no traditional clothing
- no random objects
